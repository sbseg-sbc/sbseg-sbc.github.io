IFIP technical co-sponsorship approved
Monday, 05 May 2008
SBSeg'08 is now technically co-sponsored by the International Federation for Information Processing (IFIP). The application, submitted to the Technical Committee 11 - Security and Protection in Information Systems, has been approved on May 5th.
