Call for Papers

Print-friendly version: press (3,549 KB) , standard (238 KB)
 
Information security and computing security in general characterize a research area whose visibility has increased extraordinarily in the recent years, due to the proliferation of computing systems in all activities of modern society. There is a growing demand for technologies that help to preserve the security properties of computing systems.

The Brazilian Symposium on Information and Computer System Security (SBSeg) is an annual scientific event that provides a forum for the presentation of ground-breaking research on all aspects of information security, along with tutorials and invited talks from leading researchers worldwide. The symposium is promoted by the Brazilian Computer Society (SBC). The 8th SBSeg will be held on the picturesque city of Gramado, Southern Brazil, on September 1-5 2008.

Topics of Interest


We invite submissions from academia, government, as well as industry presenting novel research on both theoretical and practical aspects of computer security. Contributions supported by implementation and experimental evidence will be particularly valued. Topics of interest include:

  • access control
  • adaptive security
  • anonymity
  • application security (distributed multimedia, Digital TV, e-banking, etc)
  • authentication and identity management
  • biometrics and biometric systems
  • certification methodologies of secure systems and software
  • computational forensics
  • contingency systems and measures upon disaster
  • cryptographic algorithms and techniques
  • cryptographic hardware, RFID and smartcards
  • distributed systems security
  • electronic voting
  • fault tolerance
  • firewall technologies
  • intellectual property protection and digital rights management
 
  • intrusion tolerance
  • key management
  • methodologies for secure systems development
  • network security
  • operating systems security
  • security in grids, P2P and overlays
  • security in middleware (Java RMI, J2EE, CorbaSec,.Net, etc)
  • security in mobile/embedded/wireless systems
  • security policies
  • security protocols
  • security standardization
  • system auditing and analysis
  • test and security evaluation
  • trust models
  • vulnerabilities, attacks and intrusion detection
  • web services security (WS-Security, SOAP,   XML,XACML, etc)

Instructions to Prospective Authors


The symposium will welcome both full papers and extended abstracts. Full papers should be up to 14 pages, including figures, tables, bibliography and appendices, formatted according to the single-column SBC template. Extended abstracts should be 2 pages long and focus on novel ideas, even if supporting results are not present (work-in-progress). Such papers will be presented during a special session during SBSeg, to foster discussion on cutting-edge research aspects. Papers can be written either in English or Portuguese.

Submitted papers must not substantially overlap papers that have been published or that are simultaneously submitted to a journal or a conference with proceedings.

The review process will be double-blind and therefore all submissions should be anonymized. This means an author’s name should only occur in references to that author’s related work, which should be referenced in the third person and not overtly distinguishable from the referenced work of others.

Both full papers and extended abstracts will be part of symposium proceedings, to be published by SBC. At least one of the authors of each accepted paper must present the paper in the corresponding technical session during the Symposium. Besides, this author must register.

Files should be in PDF form. Papers are to be submitted using the JEMS conferencing system.
